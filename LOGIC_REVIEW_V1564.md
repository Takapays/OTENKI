# Logic Review V1.5.64

The review found three main optimism paths in V1.5.63:

1. A could survive moderate mountain conditions because scoring started at average wind 7 m/s, rain 0.3 mm/h, and visibility only affected the grade below 500 m.
2. Role-based representative values (JMA rain / ECMWF wind / ICON visibility) could mask a worse scenario in another model; only a relatively large GFS divergence added a guard.
3. Nationwide A/B/C required caution conditions to persist for two hours, leaving a one-hour caution period as A.

V1.5.64 addresses all three without changing the existing model roles. Representative values remain role-based, but adverse scenarios now constrain optimism.
