# トラテン V1.6.73

全国分析の「日別判定」と詳細表示の風情報を同じ山岳向けロジックへ揃える改修です。

- 時間別A-Eへ JMA MSM 推定稜線風を反映
- 10m風モデル比較は維持し、推定稜線風グラフを追加
- 突風グラフを「推定稜線最大瞬間風速」へ変更
- 推定稜線最大瞬間風速 = max(取得できた統合突風, 推定稜線風 x 1.5)
- 日別JMA安全側判定も同じ推定最大瞬間風速を使用
- 詳細カードの「最大風速」を「最大推定稜線風」へ変更し、10m風最大値を併記
- 850/700hPaからの推定稜線風式と既存A-E閾値は変更なし
- 600hPaは診断表示用のまま判定には不使用
