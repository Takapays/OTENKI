# Traten V1.5.230

## 退行回収
- 過去の代表コース細分化が `representativeCourseExpandedPointDefs()` には残っている一方、UIの一部が生の `course.points` を参照して3点コースへ見かけ上退行する問題を修正。
- 代表コース候補を返す最終段で、監査済みの展開済みポイントを `course.points` に実体化する。
- 同一登山口に詳細ルートが存在する場合のみ、旧3点粗ルートを非表示にする。
- CT値・座標値・気象ロジックは変更しない。
