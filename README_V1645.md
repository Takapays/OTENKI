# Traten V1.6.45

V1.6.44からの差分版です。

## 変更
- 全国判定の先行（定期）キャッシュ対象を日本三百名山300座から日本百名山100座へ縮小。
- 二百名山・三百名山の全国判定機能は削除しない。ユーザー操作時のオンデマンド取得・既存共有キャッシュ利用は維持。
- V1.6.44のキャッシュ更新安定化、meteoblue 429対策、判定ロジック、UI、CT、代表コース、固定ポイントは変更しない。
- Render側にNATIONAL_PREFETCH_COUNT=300が残っていても、V1.6.45では先行キャッシュを100座に固定する。

既存の二百名山・三百名山キャッシュ行は破壊的に削除せず、TTLに従って自然失効します。
