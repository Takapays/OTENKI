# Traten V1.5.188

- スマホ代表コース表示を山選択グリッド外へ移動し、歩くスピード直下に常設。
- 代表コースプレビューはCT/中間地点展開に依存せず、生のコース点列を先に描画するフェイルセーフ方式へ変更。
- 山選択changeを独立監視し、同期・requestAnimationFrame・短時間再描画でiOS Safariの再描画競合を回避。
- 雷タイムラインはCAPE単独では雷マークを表示しない。降水を伴う場合のみ中/高を表示。
- 総合雷判定も乾いたCAPEだけでMEDIUM/HIGH/EXTREMEへ上げない。HIGH/EXTREMEは降水＋複数モデル支持を必須化。
