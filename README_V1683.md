# V1.6.83

V1.6.82で発生した全国分析の「?」大量表示と、御嶽の推定稜線風未取得を修正する版。

- 改修元を V1.6.79 に戻し、V1.6.80〜1.6.82 の全国キャッシュ完了判定変更を採用しない。
- キャッシュ行を「JMA稜線風が無い」という理由だけで非表示にしない。既存A〜Eは表示を継続する。
- 既存キャッシュにJMA稜線風系列がある場合、一覧を返す前に同じ系列から日別判定を再整合する。
- 既存キャッシュにJMA稜線風系列が無い短期予報だけ、MET/GFSを取り直さずJMAのみ軽量補完する。
- 詳細でJMA稜線風を補完した場合は共有キャッシュへ安全側の判定を書き戻す。
- 御嶽 3067m / 大山（鳥取・弥山）1709m は、既存ルートカタログにある標高を全国サーバー側でも使用する。
- 全国A〜E閾値、V1.6.78の稜線風計算、V1.6.76の山行全体地点重要度は変更しない。
- 全国共有キャッシュエンジンはV1.6.79の v16 を継続し、正常版キャッシュとの互換性を維持する。
