# OTENKI V1.5.110

代表コース細分化の反映不具合を修正。

V1.5.100以降の代表コース細分化ロジックを外部JS依存から外し、`app.js` 本体へ統合しました。
これにより差分ZIP適用後、本番で外部 enrichment JS が読まれない場合でも代表コース細分化が確実に有効になります。

確認対象:
- 仙丈ヶ岳: 北沢峠 -> 小仙丈ヶ岳 -> 仙丈ヶ岳 -> 仙丈小屋 -> 馬の背ヒュッテ -> 北沢峠
- 甲斐駒ヶ岳: 北沢峠 -> 長衛小屋 -> 仙水小屋 -> 甲斐駒ヶ岳 -> 北沢峠
- 八ヶ岳（赤岳）: 美濃戸口 -> 美濃戸 -> 赤岳鉱泉 -> 行者小屋 -> 赤岳 -> 行者小屋 -> 赤岳鉱泉 -> 美濃戸 -> 美濃戸口
