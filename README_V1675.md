# Traten V1.6.75

- V1.6.74 base.
- National decision trace is collapsed by default.
- Route-analysis visibility reliability guard: a single-model visibility value can no longer independently create E/STOP.
- Visibility E requires multi-model support plus another severe hazard.
- Multi-model visibility below 500 m can independently floor the point at D, not E.
- Single-model visibility remains a caution/reference signal and is labeled as such in hazard details.
- Wind/rain/thunder/temperature/hypothermia thresholds are otherwise unchanged.
