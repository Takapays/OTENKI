# OTENKI V1.5.120

V1.5.119 を基準に、手動ルート設計の候補地点がCT接続条件で削られ、縦走に必要な近隣ピーク・山小屋が選べなくなる回帰を修正。

## 修正
- 固定候補の表示可否を「全候補同士が確認済みCTで相互接続できるか」では判定しない。
- 座標が確定している同一山域・同一縦走回廊の固定候補は手動設計で保持する。
- CTの有無は候補表示時ではなく、実際に隣接2地点を選択した時点で既存のCT警告ロジックに任せる。
- 代表コース読込時も手動候補をCT条件で縮退させない。

## 回帰確認対象
- 八ヶ岳（赤岳）: 横岳（八ヶ岳）、阿弥陀岳、赤岳天望荘、硫黄岳山荘
- 仙丈ヶ岳: 甲斐駒ヶ岳

V1.5.119 のInstagramリール修正、全国キャッシュ、代表コース細分化などは維持。
