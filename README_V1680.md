# Traten V1.6.80

全国分析の判定正本とJMA推定稜線風の整合性修正。

- 山詳細で最新の時間別/JMAデータから再判定した結果を、ブラウザ表示だけでなくサーバーの共有キャッシュ（Supabase + ローカルポイントキャッシュ）へ書き戻す。
- 別日へ移動して戻った際に、旧B/A判定が復活する問題を防止。
- 推定稜線風は、推定式の性質上 `ridgeWind >= 10m風` であることを利用して保存データを検証。全時間0など不可能な系列を「取得済み」と扱わない。
- 不正/欠損のJMA稜線風キャッシュは、山詳細を開いた際にその山だけ直接再取得する。
- 全国キャッシュ世代を v17、ブラウザキャッシュを V1.6.80 専用へ更新。
- ABCDE閾値、推定稜線風の計算式、山行分析の地点重要度ロジックは変更なし。
