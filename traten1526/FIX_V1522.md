# V1.5.22 変更内容

## 表銀座 大天井岳〜槍ヶ岳のCT修正
- V1.5.21では `大天井岳 → 槍ヶ岳山荘` が直接未登録で、CTグラフの遠回り合成により **1090分（18時間10分）** になっていた。
- これは表銀座の標準CTとして不正。槍ヶ岳山荘グループ公式は `大天井ヒュッテ → 槍ヶ岳山荘` を約6時間40分としている。
- V1.5.22では表銀座の実際の東鎌尾根上の通過地点を明示し、各隣接区間の公開標準CTを固定した。

## 王道ルート「表銀座」の新しい中盤
`大天荘 → 大天井岳 → 大天荘 → 大天井ヒュッテ → ヒュッテ西岳 → 西岳 → ヒュッテ西岳 → 水俣乗越 → ヒュッテ大槍 → 槍ヶ岳山荘 → 槍ヶ岳`

西岳は山頂へ立ち寄る王道構成として追加。赤岩岳は槍ヶ岳山荘グループ公式が「登山道は山頂を通らずトラバース」と案内しているため、強制通過ポイントにはしていない。
