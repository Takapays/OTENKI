# V1.5.7 全国分析・百名山7日ローリングキャッシュ

## 対象
- 日本百名山: 100座
- 予報日: 翌日〜7日先
- 最大Supabase行数: 700行（100座 × 7日）
- 二百名山・三百名山: バックグラウンド維持対象外。ユーザー実行時のオンデマンド共有キャッシュは従来どおり。

## 更新方式
- Supabase fresh TTL: 4時間（14400秒）
- Render内ワーカー: 15分ごとに状態確認
- GitHub Actions: 15分ごとにRenderをwakeし、同じ更新APIを呼ぶ
- 1サイクル: 期限切れまたは欠損がある最も早い日付を1日だけ処理（最大100座）
- freshな行は再取得しない
- 初回700行が全欠損の場合、7サイクルで1巡する設計

## Supabase / API負荷方針
7日分を一度に700座処理せず、日付単位で分散します。Render FreeがsleepしていてもGitHub Actionsが15分間隔でwakeするため、初回は約105分で7日を一巡する設計です。以後は初回生成時刻が15分ずつずれるため、4時間TTLの期限も分散します。

## 互換性
旧 `NATIONAL_NEXTDAY_100_AUTO_CACHE` がRender環境に残っていても、新しい `NATIONAL_100_ROLLING_AUTO_CACHE` が未設定ならフォールバックして有効/無効設定を引き継ぎます。
