# V1.5.12 変更内容

## 全国地図の日付移動で縮尺を維持

全国一括判定の地図で、日付の `‹` / `›` を使って前日・翌日へ移動した際、ユーザーが拡大・移動した地図の中心位置とズーム倍率をそのまま維持するよう変更しました。

従来は日付変更イベントでも `fitBounds()` を実行していたため、日付を前後するたびに日本全体が収まる初期寄りの縮尺へ戻っていました。

V1.5.12ではイベントを分離し、以下の挙動にしています。

- 日付変更: 現在の中心位置・ズームを維持。マーカーと判定結果だけ更新。
- 百名山 / 二百名山 / 三百名山フィルタ変更: 対象山が収まる範囲へ `fitBounds()`。
- 初回地図表示: 従来どおり対象山全体へ `fitBounds()`。

7日ローリング共有キャッシュ、CT実利用レビュー、CT時刻入力色分け、剣山〜三嶺CT補強は変更していません。
