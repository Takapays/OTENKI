# OTENKI V1.5.113

V1.5.112 の代表コース読み込み回帰不具合を修正するホットフィックス。

## 原因
V1.5.112 では、現在画面の候補一覧に存在しない固定ポイントも代表コース解決時に参照できるようにした。
しかし、行生成 `addPointRow()` は地点IDを現在の `candidates` 一覧から選択する仕様のままだったため、固定カタログだけで解決した地点IDが選択肢に存在せず、代表コース読み込み後に地点が空になるケースが発生した。

## 修正
- 代表コースの全地点を解決した後、行を消去する前に各地点が `candidates` から選択可能か確認。
- 同一IDがあればその候補を使用。
- 同名・同種かつ120m以内の既存候補があれば既存候補を使用。
- それ以外は固定カタログの確認済み地点を候補一覧へ追加してから行を生成。

V1.5.112 の仙丈ヶ岳固定ポイント解決、赤岳鉱泉座標修正、V1.5.111 の全国300座ウォームキャッシュは維持。
