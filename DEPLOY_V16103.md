# Deploy V1.6.103

1. Deploy the V1.6.103 files to the normal GitHub / Render / Cloud Run path.
2. Open the public top page and confirm the maintenance notice appears above the normal app header.
3. Confirm `/api/health` reports `version` = `1.6.103`.
4. No environment-variable change is required.
5. The notice automatically stops displaying after 2026-11-07 JST.
