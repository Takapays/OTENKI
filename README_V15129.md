# OTENKI / トラテン V1.5.129

通過ポイントの種類選択を整理しました。

## 変更内容

- 「山小屋・テント場」と「峠・分岐」を、UI上の「山小屋・峠」に統合。
- 山小屋と既存テント場は、UI上では同じ山小屋系地点として扱う。
- 峠・分岐は同じ選択欄に表示するが、内部の `pass` は維持。
- 宿泊チェックは山小屋・既存テント場を選択した場合だけ表示。
- 峠・分岐を選択した場合は宿泊チェックを非表示にし、既存のチェックも解除。
- 登山口・下山口は従来どおり独立した種類として維持。
