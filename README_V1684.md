# トラテン V1.6.84

V1.6.83を改修元に、全国分析の「初期表示と詳細表示の等級不一致」と、御嶽・大山（鳥取）の複数日での「?」残留に限定して修正した版です。

## 修正1: 初期表示のA-Eはサーバー共有キャッシュを正本化

V1.6.83まではブラウザ localStorage の全国キャッシュを先に地図へ描画してからサーバー共有キャッシュを取得していたため、端末側が1世代古い場合に「初期E → 詳細後D」「初期D → 詳細後C」のような見かけ上の変化が起こり得ました。

V1.6.84ではブラウザキャッシュを先行描画せず、サーバー共有キャッシュの応答を初期表示の正本にします。ブラウザキャッシュは通信失敗時のフォールバックとしてのみ使用します。

## 修正2: 御嶽・大山（鳥取）の旧キャッシュを互換読込

この2山はV1.6.83以前、全国APIへ標高nullで送られていた期間がありました。V1.6.83で標高を解決した結果、キャッシュキーが変わり、過去日付の既存キャッシュが見つからず「?」になる日が発生していました。

V1.6.84では次を行います。

- クライアント側でも御嶽=3067m、大山（鳥取）=1709mを全国判定用標高として明示
- 現在の標高付きキャッシュキーを優先
- 見つからない場合のみ旧null標高キーを互換読込
- Supabase一覧読込、メタ情報確認、詳細1山読込、ローカルディスクキャッシュで互換処理
- 新規保存は現在の標高付きキーを使用

## 判定ロジック

ABCDE閾値、JMA推定稜線風の算出式、JMA worst-of、安全側floorの閾値は変更していません。
