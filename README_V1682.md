# TRATEN V1.6.82

V1.6.81を改修元として、全国分析の正本を共有キャッシュ生成時点に統一する修正版。

## 修正内容
- JMA MSMの短期予報期間（既定4日）かつ標高500m以上の山は、推定稜線風の時間系列が保存されていない行を「全国判定完了」と扱わない。
- 上記の不完全行はA/B/C/D/Eを確定表示せず、未取得扱いのまま再取得対象に残す。詳細を開いた後だけB→Dになる経路をなくす。
- 共有キャッシュのローリング更新でも、JMA推定稜線風が欠けた行をfresh完了件数に数えず、次回も再取得する。
- 詳細画面は、JMAが欠損した場合に共有キャッシュの判定をA/B側へ下げない。詳細取得は既存判定を悪化させることはあっても、改善方向へ上書きしない。
- 3000m以上で700hPa風が地形マスク等により欠損した場合のみ、既に取得している600hPa風を推定稜線風のフォールバックに使用する。700hPaが存在する場合の従来計算は変更しない。
- ABCDE閾値、通常時の推定稜線風計算、地点・山行分析ロジックは変更しない。
