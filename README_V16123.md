# V1.6.123 meteoblue 廃止

全国分析、個別ルート、宿泊分析、Instagram用予報のmeteoblue新規取得・仲裁・補完を廃止。旧APIプロキシ・診断APIも削除。画面とガイドの現行説明を更新。旧3モデル検証ページは終了案内に置換。過去の監査資料とテストは履歴として保持。

MET Norway、NOAA GFS、JMA、GEFS、Open-Meteo等の既存取得処理は維持。気温はMET主軸のまま、GFS気温への補完変更は別途検証が必要。今回の日判定閾値・気象値不足時の保守的な判定は変更しない。従来キャッシュは破棄せず、過去のmeteoblue由来の統合値が通常更新まで残り得る。キャッシュエンジンv20、TTL、Supabase読書き関数、Job頻度は維持。実通信量は本番未計測。

差分をリポジトリ直下に上書き後、本体と全国・InstagramのJobイメージを123へ更新。手動実行・キャッシュ削除・強制再取得不要。METEOBLUE_API_KEYは新コードで参照しない。旧イメージの稼働がなくなってから必要に応じて環境変数を外せる。

検証: Python/JS構文、122の判定テスト（版番号チェックのみ123に適応した一時コピー）、122の診断テスト、実稼働コードのmeteoblue参照除去、キャッシュ関数差分。旧meteoblue機能を前提とする歴史的テストは対象外。本番接続・画面操作は未検証。
