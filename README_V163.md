# Traten V1.6.3 差分

適用元: V1.6.2 FULL

## UI / 使い方
- ROUTE PLAN直下へ「01 自分専用予報作成」を移動。
- 山未選択時は通過ポイント欄を非表示。
- 代表コースの重複セレクトUIを非表示化。
- 「コースを自分で設計」を明確な縁取りボタン化。
- 代表コース読込成功後はボタンを薄色化。山・代表コース変更時に元色へ戻す。
- 使い方から「初期表示を軽くする」、スマホ版説明、SCW、前回作成ルート・分析結果、王道ルート説明を削除。
- 水場一覧・ライブカメラ説明を機能説明中心に短縮。

## 分析結果
- 風・降水グラフを左右Y軸表示へ変更。平均/瞬間最大風速は0〜10m/s、降水は0〜7mm/h固定。
- 気温・体感・雲量グラフも左右Y軸表示へ変更。
- 表示文言「突風」を「瞬間最大風速」へ統一。
- 新しい分析開始時に前回分析結果を即非表示。

## 宿泊分析
- 宿泊地ヘッダーの分析モデル/取得元説明を削除。
- 夕景・天の川・朝景の見出し文字を拡大。
- 各スコアに「夕景スコア」「天の川スコア」「朝景スコア」を明示。
- 天の川の重複するスコア/おすすめ時間帯カードを削除。
- 夜間指標と総合快適度を夕景分析より上へ移動。
- 到着時気温、夜間最低気温、最大風速、夜間降水量、月明かりカードを削除。

## 地形データ
現行は夕景・朝景の地形遮蔽用標高を Open-Meteo elevation API の Copernicus DEM GLO-90 から取得しています。気象モデル取得とは別APIですが、地形標高の供給元は現状Open-Meteoです。技術的には国土地理院DEM等への切替・フォールバック追加が可能です。
