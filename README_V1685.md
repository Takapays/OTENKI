# トラテン V1.6.85

V1.6.84を改修元に、宿泊時の夕景・天の川・朝景レポートをコンパクトなインフォグラフィック表示へ変更し、全国分析の推定稜線最大瞬間風速グラフを非表示化した版です。

## 宿泊レポートUI

- 夕景・天の川・朝景を、総合スコア・見頃/ベスト時間・主要指標・見どころが一画面で読み取りやすいコンパクトカードへ変更
- 背景画像・風景画像は追加しない
- 地名表示や装飾的なキャッチコピーは追加しない
- 長い算出説明は「算出方法」に折りたたみ、通常表示の縦長化を抑制
- 既存の夕景/天の川/朝景の算出ロジックとデータ項目は変更しない

## 全国分析

- 推定稜線風グラフの直下にあった「推定稜線最大瞬間風速」グラフを表示しない
- JMA MSM推定稜線風、安全側判定、ABCDE判定ロジックは変更しない

## 未確認

実Cloud Run/Render上での表示はこの作業環境から未確認です。デプロイ後にスマートフォン幅で夕景・天の川・朝景カードの折返しと、全国詳細で推定稜線最大瞬間風速グラフが出ないことを確認してください。
