# Traten V1.6.100

This release corrects the direction taken in V1.6.99.

The national map is no longer allowed to hide a fresher, worse opened-mountain result. Old optimistic A/B cache rows are automatically revalidated on page open, and tapping a mountain writes its live reconciled result back to the shared cache. The `最新情報取り込み` button now forces a true refresh of every displayed mountain.

The A-E thresholds, ridge-wind equations, four-hour base cache TTL, and cache-age display are unchanged.
