# Traten V1.6.8

## 適用
V1.6.7に上書きする差分ZIPです。app.jsとindex.htmlを必ず一緒に更新してください。環境変数の変更は不要です。

## 修正
- PC版の上部代表コース一覧を、常時表示の小さな縦並びカードに変更。コース名12px・経路11px。
- 読込ボタン右側の重複一覧の生成を停止。マウスオーバーの再描画イベントも削除。
- 代表コースを読み込むボタンは維持。読込後の手動設計ボタンの白色化・無効化、山・コース変更時の解除を維持。
- 山選択時の未定義関数escapeHtml呼出しを、既存のescへ修正。
- スマホ用カードのCSSとルート・CTデータは変更なし。server.pyは版番号のみ更新。

## 検証
ChromiumでPC幅1024/1280/1440/1920px、スマホ幅390px、切替境界760/761pxを検証。64項目成功。
全300山の実行時カタログはV1.6.7と一致。キャッシュテスト10件、DEMテスト5件成功。
実ブラウザ検証は配布HTML/CSS/JSをオフラインで読み込んだものです。外部API・保存領域はテスト用に分離。Render本番での確認・デプロイは未実施です。
