# Traten V1.6.4

## 地形DEM
- 日本国内の標高・夕景/朝景の稜線遮蔽解析を国土地理院DEM優先へ変更。
- 優先順: DEM5A -> DEM5B -> DEM5C -> DEM10B -> Open-Meteo Copernicus DEM GLO-90。
- DEM1Aは地平線レイのサンプル間隔に対して過剰精細で通信量が増えるため不使用。
- GSI PNG標高タイルは公式RGBデコード式で標高(m)へ変換。
- タイル単位キャッシュ・同一タイル共有・同時取得数制限を実装。
- GSIタイルはサーバープロキシでも7日キャッシュ。

## 回帰防止
- V1.6.3のUI・代表コース・CT・気象判定には変更を入れない。
