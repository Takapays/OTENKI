# OTENKI V1.5.100

代表コース細分化の全国監査を開始する第1弾です。

## 今回の実装
- 仙丈ヶ岳の代表コースを、従来の `北沢峠 → 仙丈ヶ岳 → 北沢峠` から細分化。
- 新代表コース: `北沢峠 → 小仙丈ヶ岳 → 仙丈ヶ岳 → 仙丈小屋 → 馬の背ヒュッテ → 北沢峠`。
- 小仙丈ヶ岳の固定座標を追加（OpenStreetMap node 832298351 / Mapcarta）。
- 北沢峠→小仙丈ヶ岳、小仙丈ヶ岳→仙丈ヶ岳、馬の背ヒュッテ→北沢峠のCTをYAMAP公開モデルコースのチェックポイント合算で追加。
- 仙丈ヶ岳→仙丈小屋、仙丈小屋→馬の背ヒュッテは既存の南アルプス市芦安山岳館CTをそのまま使用。
- 未確認座標・推定CTは追加していません。

## 全国監査方針
今後は「代表コースが登山口→山頂だけになっている山」を優先抽出し、固定座標と公開CTが揃った山から同じ方式で細分化します。
