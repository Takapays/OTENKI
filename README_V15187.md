# Traten V1.5.187

## 富士山・吉田ルート
- 代表コースを「富士スバルライン五合目（吉田口）→富士一館→東洋館→富士山ホテル→吉田・須走ルート山頂→富士山（剣ヶ峰）」へ詳細化。
- 下山は登りの山小屋列を逆走させず、剣ヶ峰→吉田・須走ルート山頂→吉田口五合目の別下山ルートとして扱う。
- 「吉田・須走ルート山頂」を山頂候補へ追加し、剣ヶ峰だけしか選べない状態を解消。
- 吉田口五合目→富士一館 / 東洋館 / 富士山ホテルの公開所要時間をCTへ追加。
- 代表コース用に富士一館→東洋館→富士山ホテル→吉田・須走ルート山頂の区間CTを同一公開所要時間表から接続。
- 吉田口五合目選択時は、次の空欄を「山小屋・峠」、その次を「山頂」に自動切替し、手動設計でも山小屋を選びやすくした。

## スマホ代表コース表示
- 代表コース表示領域を山選択UIのグリッド内へ移動。
- `style="display:none"` 初期値を廃止し、`aria-hidden` による明示的な mobile-only 表示制御へ変更。
- 山選択直下に代表コース名と通過順を表示する既存JSを、そのまま同一DOMへ描画。
