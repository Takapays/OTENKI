# Deploy V1.6.99

1. Upload/commit the V1.6.99 files to the GitHub repository used by Render and Cloud Run.
2. Wait for both deployments to finish.
3. Confirm `/api/health` reports `version: 1.6.99`.
4. Open the same nationwide date and verify an A/B/C/D/E marker does not change merely by tapping the mountain.
5. Press the nationwide refresh button when you want a newer shared forecast generation; that refresh may legitimately change grades for multiple mountains.
6. Confirm cache freshness / average age / oldest age / TTL 240 min remains visible.

No Supabase schema change is required.
