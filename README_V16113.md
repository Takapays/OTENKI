# Traten V1.6.113

全国キャッシュ定期更新のタイムアウト修正。V1.6.112を基準に、全国キャッシュ更新制御のみ変更。

- 定期更新対象を南→北に並べ、GFS/GEFSの地域取得範囲を小さく維持
- 定期更新専用チャンクを10座へ縮小（通常の全国分析は25座のまま）
- GitHub定期更新は15分間隔をサーバー側でも受け付ける
- 失敗開始時刻ではなく、正常終了時刻だけを次回ゲートに使用
- GFS/GEFSのHTTP待ちを240秒の定期更新deadline内に収める
- GitHub Actionsは300秒で失敗を可視化し、840秒タイムアウト後の偽成功リトライを廃止

天気判定基準、Supabaseテーブル、Instagram、UIの有名山優先順は変更なし。
