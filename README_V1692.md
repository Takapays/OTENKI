# Traten V1.6.92

V1.6.91のGFS上空風連続化に、NOAA GEFSアンサンブル平均を最後の上空風フォールバックとして追加した版です。

## フォールバック順
1. JMA MSM稜線風 / NOAA GFS deterministic上空風を一次根拠として使用。
2. 両方とも利用できない標高500m以上の山だけ、NOAA GEFS 0.5° ensemble meanの上空風を取得。
3. GEFSも利用できない場合は、10m風を稜線風へ代用せず、元判定がAならBへ抑制。元がB/C/D/Eなら「欠損だけを理由に」悪化させない。

## GEFSの扱い
- 925 / 850 / 700 hPaは、取得できた実HGTとU/V風から山頂標高へ補間。
- 500 hPaはGEFS ensemble-mean pgrb2aで風を取得できる一方、この経路では500 hPa HGTが揃わない場合があるため、高峰の最後の補助として標準高度アンカーを使う場合のみ `degraded` と明示。
- GEFS native 3時間値（06/09/12/15 JST）を全国判定の06〜15時グリッドへ線形補間。
- GEFSは低解像度・アンサンブル平均の補助情報なので、GEFSだけが穏やかでもA（良好）の確定根拠にはしない。GEFSのみの場合はAをB上限にする。
- GEFSが悪い場合は安全側のworst-ofとしてC/D/Eへ悪化させることができる。
- GEFSは全山に常時取得せず、JMA/GFS上空風が両方欠けた山だけを対象にする。
