# Traten V1.6.91

全国分析の「JMA MSM予報範囲を外れた日だけ急に楽観化する」問題に対する稜線風ロジック更新です。

## 主な変更
- NOAA GFSの925 / 850 / 700 / 600 hPaのUGRD/VGRD/HGTを全国分析で取得。
- 山頂標高を挟む実際の気圧面高度(HGT)から稜線風を補間。
- 850/700 hPaの片方が欠けても、925/600 hPaを含む取得済みの上下層で補間。
- 最新GFSサイクルで稜線風が不足した場合は、既存のGFSサイクル候補を遡って、稜線風カバレッジの高いサイクルを採用。
- HGTが欠けても850/700 hPaの実風が取得済みなら、従来の標準高度補間を「degraded」と明示して使用。
- JMA/GFSとも上空風が確認できない標高500m以上の山は、10m風を稜線風として代用せず、Aだけを禁止して最低Bにする。元がC/D/Eなら変更しない。
- 上空風取得失敗も4時間キャッシュできる状態として保存し、日付を開くたびの再取得ループを防止。
- JMA範囲外の日は、JMA APIを無駄に呼ばない。
- 詳細画面の「推定稜線風」にJMA MSMとNOAA GFSの両方を表示。

## キャッシュ
判定ロジック変更のため全国分析エンジンIDを更新しています。V1.6.90以前の全国判定キャッシュは新判定には再利用されません。

`metno-gfs-jma-ridge-gust-worstof-v17-gfs-pressure-continuity`
