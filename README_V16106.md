# トラテン V1.6.106

## Instagramカルーセル高速化
- カルーセルの1日目（通常は明日分）だけfreshキャッシュを必須とします。
- 2〜7日先は、Supabaseに保存済みで既存stale TTL（24時間）内のデータを利用できます。
- 2〜7日先について、保存済みデータが十分あれば気象プロバイダへ再取得しません。
- 不足時だけ不足山を補完します。既存の25座チャンクを維持します。
- 管理画面は日単位だけでなく山単位の進捗も表示します。

## 自動投稿
- 12:10 JSTの専用GitHub ActionsはV1.6.105と同じです。
- 自動投稿もプレビューと同じキャッシュ方針を使用します。
- 投稿直前に7日全部をfresh化し直す処理は行いません。
- 既存のInstagram投稿処理・重複投稿防止は維持します。

## 変更していないもの
- 全国分析 V19 判定ロジック
- C判定の累積風速7m/s
- 百名山100座、25座チャンク、主要山優先順
- Supabase省エグレス設計
- 4時間fresh TTL / 24時間stale TTL
