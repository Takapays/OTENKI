# Traten V1.5.189

## Fix
- 富士山・吉田ルートで「代表コースを読み込む」を押しても通過ポイントへ反映されない不具合を修正。
- 原因: 「吉田・須走ルート山頂」は既存固定地点では pass 型なのに、V1.5.187 の代表コース定義だけ peak 型で参照していたため固定地点解決に失敗していた。
- 代表コース往路/復路とも `pass / 吉田・須走ルート山頂 / 山頂ゲート` に統一。
- 吉田ルート: 富士スバルライン五合目 → 富士一館 → 東洋館 → 富士山ホテル → 吉田・須走ルート山頂 → 剣ヶ峰 → 吉田・須走ルート山頂 → 富士スバルライン五合目。
