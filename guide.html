トラテンの使い方

「どこの山が晴れるか」だけではなく、自分がその時、その場所にいるとき、空がどうなっているかを読むための山行判断ツールです。

山行設定代表コース・CT全国分析地点別予報宿泊分析登山情報気象モデル
01

山を選んで山行設定を作る

日本三百名山を対象に、山域・山から目的地を選びます。

1山域・山を選ぶ

目的の山を選ぶと、山の情報と代表コースのプレビューが表示されます。

2コースを決める

代表コースを使うか、通過ポイントを自分で組みます。

3日時を確認

標準CTがある区間は到着時刻を自動計算。必要なら手動調整できます。

4分析する

各地点の到着予定時刻に合わせた予報を取得します。

登山口山頂山小屋・テント場その他の通過地点
02

代表コースと標準CT

山選択時に代表コースを確認し、そのまま通過ポイントへ読み込めます。

代表コースをプレビュー

ボタンを押す前から、選んだ山の代表的な登山ルートを確認できます。複数ルートがある山は候補から選択します。

標準CTで時刻を自動計算

固定済みの標準コースタイム（CT）を区間ごとに加算し、出発時刻から各地点の到着予定時刻を作ります。

確認済みCTを優先

公開情報で確認できたCTを優先し、確認できない区間は「CT情報なし」または推定として区別します。

代表コースは全国の日本三百名山を対象に整備しています。ルート・CTは登山道状況や季節によって変わるため、実際の計画では最新の公式情報・山岳地図も確認してください。
03

全国分析

全国の山を地図上で比較し、「どこが良さそうか」を探す入口です。

百名山・二百名山・三百名山

表示対象を横長の切替ボタンで選択できます。初期表示は百名山です。

翌日の結果を初期表示

共有キャッシュがある場合は、翌日の判定結果を自動表示します。

地図から山情報へ

山を選ぶと評価、標準CT、代表登山口などを確認し、そのまま山行設定へ進めます。

全国判定は「山選びの比較用」です。実際の山行判断は、山行設定でルート・到着時刻を入れた地点別予報を確認してください。
04

総合判断と縦走気象グラフ

ルート全体のリスクと時間変化をまとめて俯瞰します。

総合評価

ルート全体の条件をまとめ、山行判断の入口になる評価を表示します。

最大リスク

風・雨・雷・気温・視界などの中から、特に注意すべき要素を示します。

時間変化

風・降水、気温・雲量、雷などを時系列で確認し、悪化する時間帯を把握できます。

05

地点別予報（到着時間）

トラテンの中心機能。各地点に「着く時刻」の予報を見ます。

天気・気温

到着予定時刻の空模様、気温、体感に関わる情報を確認します。

風・雨・雷

稜線行動に重要な風、降水量、雷リスクを地点ごとに確認します。

雲量・視界・予測信頼度

雲の多さ、見通し、複数モデルの一致度から予報の読みやすさを確認します。

視界目安考え方
0.5km未満危険非常に見通しが悪い
0.5〜1km警戒ルート確認に注意
1〜3km注意遠景は見えにくい
3〜10km中間域条件次第で見通しが変わる
10〜20km良好広い範囲を見渡しやすい
20km以上絶景期待遠景まで期待できる
06

山小屋・テント泊の分析

「ここに泊まる」を設定すると、到着後から翌朝までを分析します。

夜間コンディション

最低気温・体感温度、最大風速・突風、降水、雲量などを確認できます。

星空・天の川

天頂時刻、月明かり、雲量、空気質、光害の目安などをまとめて評価します。

夕景・朝景

日の入り・日の出、朝焼け・夕焼け、雲海の期待度などを確認できます。

避難小屋はトラテン上では「山小屋」に含めて扱います。通過ポイントの選択は「山小屋・テント場」にまとめています。
07

登山情報・現地確認

天気だけでなく、出発前に必要な登山口・山小屋・水場・現地映像も確認できます。

登山口アクセス情報

主要IC・道路、駐車場、公共交通、林道・狭路などの注意点を確認します。道路規制や交通時刻は必ず公式情報で最終確認してください。

山小屋・公式HP

ルート上や山域の山小屋情報から公式サイトへ移動し、営業期間・予約・最新情報を確認できます。

水場

固定監査済みの水場候補を確認できます。現地の枯渇・凍結・利用可否は変化するため最新情報を優先してください。

ライブカメラ

山域や周辺のライブカメラを開き、雲・積雪・視界など現地の様子を確認できます。

上部の「登山口・山小屋・水場・ライブカメラ」から各専用ページへ移動できます。分析画面でも利用可能な水場・ライブカメラがあるルートでは導線を表示します。
08

ルート保存・定番縦走・結果保存

繰り返し使う計画や長い縦走を、毎回ゼロから作らずに使えます。

このルートを保存

作成した通過ポイントを端末に保存し、次回の計画のたたき台として呼び出せます。

定番縦走ルート

登録済みの主要縦走ルートを読み込み、通過時刻を設定して分析できます。

前回の山行を復元

同じ端末で前回の山行設定や分析結果を再確認できる場合があります。最新予報を見るときは再分析してください。

分析結果をスクショ

分析結果を画像として残すためのスクリーンショット機能を利用できます。

09

スマートフォンで使う

山を選ぶと代表コース内容をその場で確認でき、ホーム画面からアプリのように起動できます。

代表コースを即表示

スマホでは山を選択した直後、代表コース名と「登山口 → 中間地点 → 山頂 → 下山口」の通過順を山選択欄の直下に表示します。複数コースはタップで切り替えます。

ホーム画面に追加

iPhoneはSafariの共有メニュー、Androidは対応ブラウザの「ホーム画面に追加 / アプリをインストール」から追加できます。

10

気象モデルとトラテン判定ロジック

通常時は最大6モデル、Open-Meteo障害時は最大3モデルで分析を継続します。

🇯🇵

JMA MSM｜日本

Open-Meteo経由 / 約4日先まで

日本周辺の短期予報を見る主力モデルです。

🇪🇺

ECMWF IFS｜欧州

Open-Meteo経由 / 約15日先まで

中期の傾向を見る重要な全球モデルです。

🇺🇸

GFS｜米国

Open-Meteo経由 / 約16日先まで

比較的先の日程まで使える全球モデルです。

🇩🇪

ICON｜ドイツ

Open-Meteo経由 / 約8日先まで

別系統の計算結果として一致・不一致を見る材料にします。

🇳🇴

MET Norway｜独立補強

通常時も取得 / 約9日先まで

Open-Meteoとは別の取得経路で、通常時からセカンドオピニオンとして利用します。

🌐

meteoblue｜独立補強

通常時も取得 / 最大約7日先

気温・降水・平均風は1時間値、雲・突風・大気不安定度（CAPE等）・視程は3時間値を組み合わせます。

🇺🇸

NOAA GFS｜障害時のみ直取得

Open-Meteoを経由しないバックアップ

通常時はGFSの二重計上を避けるため使いません。Open-Meteoが429・5xx・通信障害などで使えない時だけ直接取得します。

通常時：最大6モデル
Open-Meteo群（JMA MSM / ECMWF / GFS / ICON、期間に応じて最大4）と、独立補強群（MET Norway / meteoblue、最大2）を別々にまとめてから照合します。6モデルを単純平均せず、2群を同等の「予報群」として比較します。群同士が一致すれば信頼度を上げ、大きく割れれば信頼度を下げます。
Open-Meteo障害時：最大3モデル
MET Norway + meteoblue + NOAA GFS直取得へ切り替えます。代表値は中央値中心として1モデルだけの外れ値に引っ張られにくくしつつ、強雨・突風・CAPEなど安全上重要な悪天側の情報は平均で消さず残します。
モデル数は予報期間や各提供元の取得可否で変わります。モデル一致度が高くても「必ず当たる」という意味ではありません。山岳では局地風・地形・雲・霧の発生などで予報との差が出ることがあります。
!

利用上の注意

トラテンは山行判断を補助する情報ツールです。

登山の可否、安全性、登山道の通行可能性を保証するものではありません。最新の気象情報、登山道・林道、山小屋営業、火山情報、入山規制、積雪・残雪、交通機関などの公式情報を必ず確認し、現地状況を優先してください。
