# Traten V1.6.90

V1.6.89を基準に、全国分析の共有キャッシュを自動表示した時点でも「キャッシュ年齢 / 4時間TTL残り」を常時表示する小変更です。

## 変更点
- 日付変更・初期表示・山カテゴリ切替で `cacheOnly:true` の共有キャッシュを表示した場合にも、キャッシュ年齢とTTL残り時間を表示。
- 「全国を判定」実行後に表示していたキャッシュ年齢表示はそのまま維持。
- 全国判定ロジック、Supabase優先/ローカルフォールバック、気象モデル、キャッシュTTLは変更なし。
- app.js / server.py / 画面表示バージョンを V1.6.90 に同期。

## 確認方法
全国分析を開くか日付を切り替え、共有キャッシュが存在する場合に「全国を判定」を押さなくてもステータス欄へ `キャッシュ年齢 約X分 / 4時間TTL残り 約Y分` が表示されることを確認してください。
