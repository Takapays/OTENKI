# Traten V1.5.221

## Open-Meteo 429時の予測信頼度ロジックを見直し
- Open-MeteoがHTTP 429でも、meteoblueを正常取得できた場合は「429そのもの」を理由に予測信頼度を一律ダウンしない。
- 429時のmeteoblueは「複数モデル統合予報」として扱い、取得できたMET Norway / NOAA GFSは独立クロスチェックとして併用。
- 実際の予報間の差が大きい場合は、従来どおりMEDIUM / LOWへ低下する。
- 予報リードタイム（8日先・12日先など）による信頼度調整は従来どおり維持。
- Open-Meteoが429以外の障害で失敗し、通常の予備系だけになった場合の慎重な信頼度補正も維持。
- 画面表示・気象モデル詳細ではmeteoblueを「複数モデル統合」と明示。
- Open-Meteo 429時のステータス文言を、meteoblueを軸に予備系へ切り替える説明へ変更。
