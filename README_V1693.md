# Traten V1.6.93

V1.6.92のGEFSフォールバックを維持したまま、上空風取得障害が全国分析のベースGFSまで巻き込まないようにした耐障害性修正版です。

主な変更:
- 拡張GFS（上空風込み）が失敗したら軽量なベースGFSへ自動リトライ
- ベース予報の充足を稜線風より優先
- 直前GFSサイクルまでに限定し、その先はGEFSへ
- ベース予報がない山にはGEFSを無駄打ちしない
- 0件時の「混み合っています」表示を実際のrate-limit時だけに限定
- 全国キャッシュエンジンIDはV1.6.92と同一で、既存キャッシュをそのまま利用

詳細は `RELEASE_AUDIT_V1693.md` と `DEPLOY_V1693.md` を参照してください。
