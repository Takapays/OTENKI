# トラテン V1.6.2

V1.6.1の退行復旧成果を保護したまま、代表コース欠落再監査、全国キャッシュGitHub Actions、使い方の気象モデル説明を更新した統合版。

## 代表コース再監査
V1.6.1で代表コースが0件だった6山を過去版と現行規制まで再確認。
- 箱根山: 旧大涌谷ルートは復活させず、2025年再開後の合法ルート「駒ヶ岳頂上駅→箱根駒ヶ岳→神山→頂上駅」を新規復旧。固定座標と公開チェックポイントCTのみ。
- 渡島駒ヶ岳: 旧剣ヶ峯ルートは入山規制により復活不可。現在合法なのは6合目駐車場〜馬ノ背。CTは確認できたが馬ノ背の固定座標を今回の資料だけでは確定できず、座標推測禁止のため未登録。
- 太平山: 旧旭又は閉鎖。丸舞ルートは2026年8月に通行可能で、公式往路CTも確認済み。ただし固定通過地点の公開座標を十分に確定できず、座標推測禁止のため未登録。
- 景鶴山: 正規登山道なし・土地所有者が登山を認めていないため復活禁止。
- 草津白根山: 2026年時点も立入規制区域への登山利用不可のため復活禁止。
- 桜島（御岳）: 火口周辺立入禁止。旧山頂ルートは復活禁止。

したがって代表コース0件は6→5。安全上・検証上の理由がある4山と、座標未確定の1山を数字合わせで捏造して0件にはしていない。

## GitHub Actions / 全国キャッシュ
- 先行キャッシュ対象300座、翌日〜7日、4時間TTLを維持。100座へ戻していない。
- `NATIONAL_OUTLOOK_CHUNK_SIZE`既定25と25座ごとのチェックポイント保存を維持。
- workflowは`pull_request`で起動しない。`schedule`と`workflow_dispatch`のみ。
- 同時実行をconcurrencyで抑止。
- 429/取得タイムアウト等の回復可能な部分更新はJSON上`ok=false`を維持しつつHTTP 200でschedulerAcceptedとし、GitHubを不必要に失敗扱いにしない。DB書込/読戻し・設定不備は引き続きHTTP 503。

## 使い方
- 先行キャッシュ説明を100座→300座へ修正。
- meteoblueを通常時から使う独立補強として明記。
- 詳細A〜E: Open-Meteo(JMA/ECMWF/ICON/GFS) + MET Norway + meteoblue。
- Open-Meteo 429時: meteoblue + MET Norway + NOAA GFS直取得へ継続。meteoblue利用可能なら429だけで信頼度を一律低下させない。
- 全国A/B/C: MET Norway + NOAA GFS共有キャッシュの別系統。
