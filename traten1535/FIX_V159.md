# V1.5.9 変更内容

1. 全国一括判定の地図右上を `‹ 日付 ›` に変更。
2. `‹` で前日、`›` で翌日へ移動し、変更後すぐSupabase共有キャッシュを確認。
3. 日付inputのmin/maxを超える矢印はdisabled。
4. 百名山100座×翌日〜7日先のローリングウォームキャッシュはV1.5.7/V1.5.8のまま維持。
5. 個別分析の匿名ログへ、実利用ルート内の「推定CT / CT情報なし」隣接区間を追加。
6. usage-dashboardに「CT要確認区間」を追加し、利用回数・ユニークセッション・最終利用で優先順位を確認可能にした。
7. 利用実績だけではCTを自動確定しない。公開標準CTの裏取り後にのみ確認済みCTへ昇格する。
8. progressive weather rendering、既存CT、水場、水場V2、共有キャッシュ設計を維持。
