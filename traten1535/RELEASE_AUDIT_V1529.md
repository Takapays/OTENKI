# V1.5.29 Release Audit

## 対象
- 基準: `traten-v1.5.28-full.zip` を展開した実ソース
- 変更: 04 地点別予報パネルの指標配置調整（風向カード廃止 / 視界移動 / 風カード内へ風向統合）

## 実施した変更
- 地点別予報カードの独立した「風向」パネルを削除。
- 「視界」カードを4枠目として表示する4カラム構成へ変更。
- 「風」カード内に、風速の下段として 風向矢印・方角・度数 を表示するインライン領域を追加。
- PCでは4列、スマホでは2列×2段で崩れにくいよう、末尾上書きCSSを追加。
