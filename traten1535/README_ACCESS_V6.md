# 登山口アクセス V6 / V1.4.75 修正版

- 全国主要登山口アクセスDBを追加
- 登録済み: 「アクセス」
- 未登録: 「アクセス情報なし」
- V1.4.75ではMutationObserverを完全撤去し、通過ポイント行生成時だけアクセスUIを接続します。
- 全国山行マップ、代表コース読込、通過ポイント読込の既存処理には干渉しません。

## V1.4.74からの修正
V1.4.74ではアクセスUIがページ全体のDOM変更を監視しており、全国マップ描画や代表コース行追加時に大量再走査・自己再発火する問題がありました。V1.4.75では監視処理そのものを廃止しています。


## V1.4.76 regression fix
- 「通過ポイントを読み込む」を代表コースUIから分離して常時表示。
- 全国山行マップの判定を50座ずつ分割取得。
- Leaflet読込失敗時でも全国判定ボタンは動作。
- 全国判定APIの直接受付上限を300地点へ拡張。
