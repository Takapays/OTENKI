# V1.5.27 変更内容

## 1. 縦走気象グラフの日付表示
- 「風・降水」「気温・雲量」の各グラフ直下に日付帯を追加。
- 同一日の連続地点は1つの日付帯としてまとめて表示。
- 日付が変わる地点と地点の中間位置に縦の破線を表示。
- 日付境界線はプロット領域内だけに表示し、既存の値・バー・折れ線・地点番号を残す。

## 2. 継承元
- V1.5.26 full ZIPを直接展開して基準ソース化。
- V1.5.23 CT解決修正、V1.5.24 CT/宿泊修正、V1.5.25〜V1.5.26 地点別予報コンパクト化を含む状態を保持。

## 3. 非変更項目
- CTテーブル / CT解決順
- 固定座標 / 固定水場 / 固定ライブカメラ
- 代表コース / 王道ルート
- 気象取得・分析ロジック
- progressive weather rendering
