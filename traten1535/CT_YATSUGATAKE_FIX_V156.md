# V1.5.6 八ヶ岳 CT確定

- 赤岳 → 阿弥陀岳: **95分**
  - 出典: YAMAP「美濃戸登山口-地蔵ノ頭 周回コース」標準モデル
  - 赤岳→分岐25分 + 分岐→中岳15分 + 中岳→中岳のコル30分 + 中岳のコル→阿弥陀岳25分 = 95分
- 阿弥陀岳 → 美濃戸口: **201分（3時間21分）**
  - 出典: YAMAP「美濃戸口登山口-御小屋山-阿弥陀岳 往復コース」標準モデル
  - 阿弥陀岳→八ヶ岳山荘（美濃戸口）の下山チェックポイント合算 = 201分

固定CTとして `app.js` の `YATSUGATAKE_CHUSHIN_COURSE_TIMES` に追加。
