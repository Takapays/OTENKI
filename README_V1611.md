# Traten V1.6.11

## 変更内容

全国分析だけを対象に、次を変更した差分リリースです。

- 全国判定を A/B/C から A/B/C/D/E の5段階へ変更
  - A: 良好
  - B: 軽い注意
  - C: 注意
  - D: 悪い
  - E: 非常に悪い
- MET Norway / NOAA GFS の2モデル取得時は、6〜15時の同じ時刻の予測値を平均して中心値を作成してから判定
- どちらか一方のモデルが D/E 相当の場合は、平均で警戒を解除しない安全下限を維持
- モデル差が大きい場合は山詳細に明示
- 全国分析で山をタップした際、MET Norway / NOAA GFS / 中心値の時間別グラフを追加
  - 風速
  - 突風
  - 降水
- 全国分析に A〜E の凡例と「山をタップ」の案内を追加
- 山詳細に ABCDE 判定基準を追加
- 詳細グラフは山タップ時だけ取得し、全国300座の初期取得量は増やさない
- MET Norway に1時間降水値が存在しない時間は、モデル比較上 0 mm とみなして平均しない
- 全国分析のキャッシュエンジン/ブラウザキャッシュキーを更新し、旧ABCキャッシュとの混在を防止
- Instagram既存ABCテンプレートは表示互換を維持し、全国分析本体のABCDE化と分離

## 判定境界

既存の気象閾値自体は変更していません。

- 注意: 風 5m/s / 突風 12m/s / 雨 0.1mm/h 以上
- 強い: 風 9m/s / 突風 18m/s / 雨 1.5mm/h 以上
- 極端: 風 15m/s / 突風 25m/s / 雨 6mm/h 以上

時間回数による5段階化のみを追加しています。

- A: 注意時間 0
- B: 注意時間 1
- C: 注意時間 2以上、または強い時間 1
- D: 強い時間 2以上
- E: 極端な時間 1以上

## 適用元

V1.6.10 に上書きする差分ZIPです。正本 V1.5.231 = V1.6.1 を基準に退行監査済みです。
