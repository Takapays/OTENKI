# V1.6.124 全国共有キャッシュ TTL 統一

JST基準の取得時点からの予報日差に応じ、全国Job・手動取得・山の詳細の新規共有キャッシュを同一の6/8/12時間ルールで保存する。Jobの既存関数を共用する。当日・翌日360分、2〜3日先480分、4日先以降720分。取得済みの行は生成時刻・期限を保持するため、一時的に240分の旧行や日付経過による異なる期限が混在する。通常更新で置換し、強制再取得や期限延長はしない。内部の短時間フォールバックとブラウザ障害時用キャッシュ、24時間のstale保持、上流GRIBキャッシュの設定は従来通り。

初期表示に設定TTLと保存TTL（最短〜最長）を明示。鮮度数は実際の保存期限から計算する。新しいAPI応答のメタ情報は既存の時刻情報から計算し、Supabaseへの追加問い合わせ・保存項目・書込処理はない。v20、Job周期、気象判定、meteoblue廃止は維持する。本番通信量は未測定。

差分をリポジトリ直下に上書き。本体と全国分析Jobを124へ更新する。Instagram Jobは今回の修正対象外。通常の定時更新に任せ、手動実行やキャッシュ削除は不要。

検証: 新規TTL・JST日付境界・旧メタ保持・混在TTL表示用応答・鮮度、全国Job模擬テスト、書込検証、既存気象判定（版番号チェックのみ一時的に124へ合わせたテスト）、診断、Python/JS構文。実環境未検証。
